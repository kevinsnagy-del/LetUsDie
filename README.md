# Let Us Die *(beta)*

Online co-op for **LET IT DIE** through Steam, built on [Mod Drive 9000](https://github.com/kevinsnagy-del/ModDrive9000). It works in the base game, and in POSTMORTEM games when the [POSTMORTEM](https://github.com/kevinsnagy-del/Postmortem) plug-in is installed.

- A **MULTIPLAYER** button in the pause menu lets you host a lobby or join a friend's.
- Players see each other's characters. A follower plays the host's floor layout, and the enemies stay in sync.
- Optional friendly fire, a ready check at boss doors, shared notices, and co-op error codes on the game's own error screen.

**Every player needs Mod Drive 9000 and Let Us Die, on the same versions.**

This is a **beta**: co-op is new ground in this game, so expect desyncs and rough edges. Your saves are backed up before every install (`ModDriveInstaller\RestoreSaves.bat`).

## Install

1. Install [Mod Drive 9000](https://github.com/kevinsnagy-del/ModDrive9000) first.
2. Download `LetUsDie-<version>.zip` from [Releases](../../releases), close the game, and unzip it into the LET IT DIE folder.
3. Run `ModDriveInstaller\Install.bat` again.

**Updates:** run `ModDriveInstaller\Update.bat`. **Remove:** run `ModDriveInstaller\Remove.bat` and type `letusdie`.
